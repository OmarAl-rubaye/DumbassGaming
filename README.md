Tämä repository sisältää yksinkertaisen selainpelisivuston, jossa on viisi erillistä peliä, etusivu ja credits-sivu. Sivusto on rakennettu HTML:llä ja CSS:llä, ja tiedostot ovat järjestettynä siten, että jokaiselle pelille on oma HTML-sivunsa.

This repository contains a simple browser game website with five separate games, a homepage, and a credits page. The site is built using HTML and CSS, and each game has its own dedicated HTML file.
